# nikitajoisa.github.io

👋 Hi, I'm Nikita, this is the source code for my personal portfolio site, live at **[nikitajoisa.github.io](https://nikitajoisa.github.io)**.

I build websites and I'm nosy about data. Currently at Leisureworld in Cork, doing a bit of both.

## What's in here

```
.
├── index.html      → the site structure (HTML)
├── styles.css      → all the styling (CSS)
└── README.md       → this file
```

Hand-coded with HTML & CSS. No frameworks, no build tools, no trackers. Just two files and a bit of care.

## Built with

- HTML & CSS
- [Fraunces](https://fonts.google.com/specimen/Fraunces) (display font) + [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) (body font) via Google Fonts
- Hosted on GitHub Pages

## Running it locally

No build step. Just clone and open:

```bash
git clone https://github.com/nikitajoisa/nikitajoisa.github.io.git
cd nikitajoisa.github.io
open index.html
```
